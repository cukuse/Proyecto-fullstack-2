 # Proyecto Fullstack 2 = Tu Dia Especial

Plataforma web para la organización de eventos, celebraciones y entregas de sorpresas personalizadas, enfocada principalmente en celebraciones pequeñas y fechas especiales durante el año.

## Descripción

El proyecto busca desarrollar una plataforma donde los usuarios puedan encontrar y agendar diferentes tipos de celebraciones y servicios.

La propuesta considera dos líneas principales:

Eventos y celebraciones: cumpleaños, aniversarios, reuniones, celebraciones formales y otros eventos.

Sorpresas y entregas: flores, dulces, regalos, detalles y combinaciones personalizadas para sorprender a otra persona.

La plataforma también considera actividades y promociones relacionadas con fechas especiales y festividades sociales.

## Fechas especiales

El sistema contempla trabajar con fechas relevantes durante el año, permitiendo preparar campañas y servicios con anticipación.

Entre las fechas consideradas se encuentran:

-San Valentín

-Flores Amarillas

-Día de la Mujer

-Día de la Madre

-Navidad

-Cumpleaños

-Aniversarios

-Graduaciones
## 
La planificación contempla la posibilidad de realizar reservas con una anticipación de al menos 3 meses para determinadas actividades.

## Enfoque del proyecto

El proyecto se enfoca principalmente en el público que busca organizar celebraciones pequeñas y personalizadas, sin dejar de considerar eventos formales y otras actividades de mayor tamaño.

La idea es entregar una experiencia sencilla para:

Revisar los servicios y productos disponibles.

Seleccionar una celebración u ocasión.

Personalizar la solicitud.

Agendar una fecha.

Gestionar el pedido o evento.

## Funcionalidades principales

Actualmente el proyecto contempla páginas y funcionalidades relacionadas con:

Registro e inicio de sesión.

Menú principal.

Catálogo de productos.

Perfil de usuario.

Información de la empresa.

Contacto.

Solicitud y gestión de eventos.

Validaciones mediante JavaScript.

Gestión de información mediante Python.

Documentación de requerimientos.

## Tecnologías

El proyecto utiliza actualmente:

HTML5 — estructura de las páginas.

CSS3 — estilos y diseño visual.

JavaScript — validaciones e interacción.

Python — gestión y lógica complementaria.

Git / GitHub — control de versiones y trabajo colaborativo.

## Roles principales

-Cliente

Podrá consultar productos y servicios, revisar alternativas para distintas celebraciones y realizar solicitudes o reservas.

-Trabajador

Podrá apoyar la gestión de pedidos, eventos y solicitudes realizadas por los clientes.

-Administrador

Tendrá acceso a las funciones de gestión y administración general de la plataforma.
